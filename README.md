### Ritik Sharma — Software Engineer, Backend & AI

Node.js and TypeScript services, RAG pipelines and browser-automation agents. 1+ year at Oracle building AI and automation tools for Fusion SaaS.

**Oracle** · Customer Success Services · Fusion SaaS (HCM, ERP, SCM) · Jun 2025 – Oct 2026

- **Discovery Probe (RAG text-to-SQL):** co-built per-pillar pipelines over a 4,000+ table schema (doc scraping, table-aware chunking with contextual headers, embeddings, top-k retrieval). ~2× per-person query throughput, ~900 validated SQL queries; fixed value-grounding errors by profiling stored values.
- **Test Automation Agent:** Codex plugin with 61 domain playbooks that completes outdated test scripts (team-adopted), extended into a Node.js runtime of 6 process-isolated workers running parallel Playwright lanes. 7 scenarios end to end, 76 automated tests. Paused rollout after estimating LLM cost per test above manual execution.
- **Manual Test Recorder:** Manifest V3 Chrome/Edge extension with a zero-dependency XLSX writer built from the OOXML spec. Adopted by ~40 testers, ~25% daily throughput lift (team-reported).
- **Release Impact Reports:** prepared data, updated templates and extended the React UI of an LLM agent that generates customer impact reports. 100+ reports, 1–2 hours each instead of 1–2 weeks.
- **Regression automation:** 330+ scripts automated, the most on my team.
